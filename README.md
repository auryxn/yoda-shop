# yoda-shop

> Часть портфолио: [auryxn.codes](https://auryxn.codes) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Интернет-магазин металлических чехлов для телефонов: тёмное фэнтези-оформление, корзина, оформление заказа через Stripe и полноценная админ-панель.

## Что это

yoda-shop — учебный демо-магазин вымышленного бренда **YODA** (металлические
чехлы для смартфонов и планшетов). Проект показывает полный цикл интернет-магазина:
от витрины и карточки товара до корзины, промокодов и оплаты через Stripe
Checkout, плюс отдельная **админ-панель** с дашбордом, складом, заказами, скидками
и редактором контента.

Оформление — в духе **тёмного фэнтези** (пиксельный шрифт Press Start 2P, тёмный
фон с объёмным «туманом», золотистая палитра) с переключателем на **светлую тему**.
Фронтенд — React + Vite (SPA с клиентским роутингом), бэкенд — Node + Express,
который в продакшене отдаёт ещё и собранный фронтенд. Данные хранятся в памяти
сервера (сид-данные: 5 товаров, 6 категорий, 7 заказов, промокоды, баннер, тексты
страниц и настройки магазина).

## Возможности

- **Витрина и каталог** — баннер с главной страницы, сетка активных товаров,
  карточка товара с ценой, старой ценой, описанием, категорией и наличием.
- **Корзина** — добавление/удаление товаров, количество, бейдж с числом позиций
  в навигации, всплывающие уведомления (toast).
- **Оформление заказа** — ввод промокода с проверкой на сервере, расчёт итога
  со скидкой, оплата через Stripe Checkout, страницы успеха и отмены платежа.
- **Промокоды** — проверка кода (`POST /api/discounts/check`), активные и
  неактивные скидки, автосоздание купона Stripe при оплате.
- **Админ-панель** (`/admin`, вход по паролю) — дашборд со статистикой (выручка,
  заказы, новые заказы, низкий остаток, средний чек), аналитика (выручка по
  статусам, популярные товары), CRUD по товарам и категориям, список заказов со
  сменой статуса, управление скидками, редактор баннера и текстов сайта, SEO и
  методы доставки/оплаты.
- **Тёмная / светлая тема** — переключатель в навигации, выбор сохраняется в
  `localStorage`.
- **Информационные страницы** — About, Contact, FAQ.
- **Адаптивная вёрстка** и авто-роутинг через `react-router-dom`.

## Стек

| Слой      | Технология |
|-----------|------------|
| Frontend  | React 18 + Vite + React Router |
| Стили     | CSS (пиксельный шрифт Press Start 2P, SVG-иконки, фоновые изображения) |
| Backend   | Node.js + Express + CORS + Morgan |
| Оплата    | Stripe (Checkout Sessions, купоны) |
| Конфиг    | dotenv (`.env`) |
| Деплой    | bash-скрипт `deploy.sh` для Ubuntu (Node 22, сборка Vite, запуск сервера) |

## Как запустить

```bash
# 1. Установить зависимости клиента и сервера
npm run setup          # = server npm install && client npm install

# 2. Запустить в режиме разработки (API + Vite dev-сервер)
npm run dev            # API -> http://localhost:4000, веб -> http://localhost:5173
```

Откройте **http://localhost:5173**. Vite проксирует запросы `/api` на
`http://localhost:4000`. Админка доступна по адресу `/admin` (пароль по умолчанию —
`admin`).

Отдельные команды:

```bash
npm run dev:server     # только API (node --watch)
npm run dev:client     # только фронтенд (vite)
npm run build          # прод-сборка фронтенда в client/dist
npm start              # запуск API-сервера
```

Для оплаты через Stripe задайте ключ в `server/.env`:

```
PORT=4000
NODE_ENV=development
STRIPE_SECRET_KEY=sk_test_...
```

Без ключа сервер поднимается с плейсхолдером, а создание сессии оплаты вернёт
ошибку — остальной магазин (каталог, корзина, админка) работает без Stripe.

## API (кратко)

```
GET    /api/health
GET    /api/products            список товаров
GET    /api/products/:id
POST   /api/products            создать товар (админка)
PUT    /api/products/:id        обновить товар
DELETE /api/products/:id        удалить товар

GET    /api/categories          категории (+ CRUD)
GET    /api/orders              заказы
PUT    /api/orders/:id/status   сменить статус заказа
GET    /api/dashboard           сводная статистика
GET    /api/analytics           выручка по статусам, популярные товары

GET    /api/discounts           промокоды (+ CRUD, toggle)
POST   /api/discounts/check     проверка промокода

GET    /api/banner              баннер главной (POST — изменить)
GET    /api/site-texts          тексты страниц (POST — изменить)
GET    /api/settings            настройки магазина (POST — изменить)

POST   /api/create-checkout     создать Stripe-сессию оплаты
POST   /api/checkout/verify     подтвердить оплату и создать заказ
```

## Структура проекта

```
yoda-shop/
├─ client/                 # фронтенд (React + Vite)
│  ├─ index.html
│  ├─ vite.config.js       # порт 5173 + proxy /api -> :4000
│  ├─ public/assets/       # фоны (dark/light fantasy) и заглушка товара
│  └─ src/
│     ├─ App.jsx           # роутинг + toast
│     ├─ context/          # CartContext, ThemeContext
│     ├─ components/       # Navbar, Header, Footer, Taskbar, PageTransition
│     └─ pages/            # Home, Catalog, Product, Cart, Checkout,
│                          # CheckoutSuccess/Cancel, Admin, About, Contact, Faq
├─ server/                 # API (Node + Express)
│  ├─ index.js             # все маршруты, сид-данные, Stripe
│  ├─ start.sh
│  └─ .gitignore           # игнорирует node_modules, .env
├─ backup-xp/              # старая версия оформления в стиле Windows XP
├─ deploy.sh               # one-click деплой на Ubuntu
└─ restore-julius.sh       # скрипт само-восстановления окружения
```
